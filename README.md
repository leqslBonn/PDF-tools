# PDF Toolkit

เว็บเครื่องมือ PDF 19 รายการ (ฟังก์ชันเดียวกับ sbtc.pntc.ac.th/pdf-tools) — **ประมวลผลในเบราว์เซอร์ทั้งหมด** ไม่มี backend ไฟล์ไม่ถูกอัปโหลด

| เครื่องมือ | ไฟล์ | หมายเหตุ |
|---|---|---|
| สแกนเอกสาร | `js/tools/scan.js`, `js/scan-core.js` | ถ่ายทีละภาพ / ถ่ายรวด (กล้องสด) / เลือกไฟล์, ครอบ 4 มุม (perspective), ลบเงา, ขาวดำ |
| รวมไฟล์ PDF | `merge.js` | ลากสลับลำดับ |
| จัดหน้า PDF | `organize.js` | ลากสลับ, หมุน, ตัดหน้า |
| แยกไฟล์ PDF | `split.js` | เลือกหน้า / ช่วงหน้า / ทุก N หน้า (หลายไฟล์ → .zip) |
| ลดขนาด PDF | `compress.js` | บีบอัดรูปในไฟล์ (ข้อความคงเดิม) หรือแปลงทั้งหน้าเป็นภาพ, หรือกำหนดขนาดเป้า ≤ 1/2/5 MB |
| PDF → JPG/PNG | `image.js` | สูงสุด 50 หน้าแรก, เลือกดาวน์โหลดทีละหน้า/ zip |
| ลดขนาดไฟล์ภาพ | `image-compress.js` | JPG / PNG / WEBP |
| JPG → PDF | `jpg-to-pdf.js` | A4 / Letter / Legal / ตามขนาดรูป |
| ใส่เลขหน้า | `page-number.js` | เลขอารบิก / เลขไทย, 6 ตำแหน่ง, หลายรูปแบบ |
| ใส่ลายน้ำ | `watermark.js` | ข้อความหรือรูปภาพ, จุดเดียวหรือปูเต็มหน้า |
| ครอบตัดขอบ | `crop.js` | ทุกหน้าเท่ากัน หรือแยกทีละหน้า, ตัดขอบขาวอัตโนมัติ |
| ใส่รหัสผ่าน | `protect.js` | เข้ารหัสด้วย @cantoo/pdf-lib + ตั้งสิทธิ์ พิมพ์/คัดลอก/แก้ไข |
| เซ็นเอกสาร | `sign.js`, `js/editor.js` | วาด / อัปโหลด (ลบพื้นขาว) / พิมพ์, จำลายเซ็นไว้ในเครื่อง |
| เพิ่มข้อมูลใน PDF | `form.js`, `js/editor.js` | ข้อความ (ภาษาไทย), สัญลักษณ์ ✓ ✗, วันที่, รูปภาพ |
| สำเนาบัตร / รับรองสำเนา | `id-copy.js` | บัตรหน้า-หลังขนาดจริงบน A4 หรือประทับทุกหน้าของ PDF: ขีดคร่อม "ใช้สำหรับ...เท่านั้น", สำเนาถูกต้อง, ลายเซ็น, ชื่อ, วันที่ |
| ปลดรหัส PDF | `unlock.js` | ปลดล็อกไฟล์ที่ห้ามแก้/พิมพ์/คัดลอก หรือเอารหัสเปิดออก (ต้องรู้รหัส) |
| ปิดข้อมูลส่วนตัว | `redact.js` | ลากวาดกรอบ หรือค้นหาเลขบัตร/เบอร์โทร/อีเมล/เลขบัญชี/ข้อความ — หน้าที่มีกรอบถูกแปลงเป็นภาพ ข้อมูลใต้กรอบหายจริง |
| กรอกแบบฟอร์ม PDF | `fill.js` | กรอกช่องที่มีในไฟล์ (ข้อความ/ติ๊ก/ตัวเลือก) แบบล็อก (ไทยถูกทุกแอป) หรือแบบยังแก้ได้ |
| แก้ข้อความใน PDF | `edit-text.js` | แตะบรรทัดเพื่อแก้/ลบ จับแบบอักษร ขนาด สีตัวอักษร สีพื้นอัตโนมัติ, ปิดทับ หรือลบของเดิมจริง (แปลงหน้าเป็นภาพ) |

## รัน

ต้องเปิดผ่าน web server (เปิดไฟล์ตรงแบบ `file://` ไม่ได้ เพราะใช้ ES modules)

```bash
python -m http.server 8765
```

แล้วเปิด http://localhost:8765

## Deploy

ก่อน deploy ทุกครั้ง: `python scripts/gen_sw.py` (อัปเดตรายการไฟล์ที่เก็บไว้ใช้ออฟไลน์ + เลขเวอร์ชัน ให้แอปที่ติดตั้งไว้ได้อัปเดต)
ไอคอนแอป: `python scripts/make_icons.py`


เป็น static site ล้วน — ลากทั้งโฟลเดอร์ไปวางใน Netlify / GitHub Pages / Cloudflare Pages ได้เลย

## ไลบรารี (อยู่ใน `vendor/`, ใช้แบบ offline ได้)

pdf-lib (@cantoo fork, รองรับเข้ารหัส) · pdf.js 3.11 · JSZip · SortableJS · pako
ฟอนต์ไทย (Kanit, IBM Plex Sans Thai, Sarabun, Charm, Mali, Itim, Srisakdi) เก็บไว้ใน `vendor/fonts/` + `css/fonts.css` — ไม่เรียก Google หรือบริการภายนอกเลย และเปิดหน้าเว็บครั้งเดียวแล้วใช้ออฟไลน์ได้ทุกเครื่องมือ (modulepreload)

ไฟล์ PDF ที่ติดรหัส: ถ้าเป็นรหัสเจ้าของ (เปิดอ่านได้แต่ห้ามแก้) จะปลดให้อัตโนมัติ ถ้าต้องใส่รหัสเพื่อเปิด จะถามรหัสก่อน

ข้อความภาษาไทยทุกจุด (เลขหน้า ลายน้ำ ข้อความในฟอร์ม) วาดผ่าน canvas แล้วฝังเป็นภาพ PNG ความละเอียด 4 เท่า เพื่อให้สระ/วรรณยุกต์ถูกต้องเสมอ
