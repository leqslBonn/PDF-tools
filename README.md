# PDF Toolkit

เว็บเครื่องมือ PDF 14 รายการ (ฟังก์ชันเดียวกับ sbtc.pntc.ac.th/pdf-tools) — **ประมวลผลในเบราว์เซอร์ทั้งหมด** ไม่มี backend ไฟล์ไม่ถูกอัปโหลด

| เครื่องมือ | ไฟล์ | หมายเหตุ |
|---|---|---|
| สแกนเอกสาร | `js/tools/scan.js`, `js/scan-core.js` | ถ่ายทีละภาพ / ถ่ายรวด (กล้องสด) / เลือกไฟล์, ครอบ 4 มุม (perspective), ลบเงา, ขาวดำ |
| รวมไฟล์ PDF | `merge.js` | ลากสลับลำดับ |
| จัดหน้า PDF | `organize.js` | ลากสลับ, หมุน, ตัดหน้า |
| แยกไฟล์ PDF | `split.js` | เลือกหน้า / ช่วงหน้า / ทุก N หน้า (หลายไฟล์ → .zip) |
| ลดขนาด PDF | `compress.js` | บีบอัดรูปในไฟล์ (ข้อความคงเดิม) หรือแปลงทั้งหน้าเป็นภาพ |
| PDF → JPG/PNG | `image.js` | สูงสุด 50 หน้าแรก, เลือกดาวน์โหลดทีละหน้า/ zip |
| ลดขนาดไฟล์ภาพ | `image-compress.js` | JPG / PNG / WEBP |
| JPG → PDF | `jpg-to-pdf.js` | A4 / Letter / Legal / ตามขนาดรูป |
| ใส่เลขหน้า | `page-number.js` | เลขอารบิก / เลขไทย, 6 ตำแหน่ง, หลายรูปแบบ |
| ใส่ลายน้ำ | `watermark.js` | ข้อความหรือรูปภาพ, จุดเดียวหรือปูเต็มหน้า |
| ครอบตัดขอบ | `crop.js` | ทุกหน้าเท่ากัน หรือแยกทีละหน้า, ตัดขอบขาวอัตโนมัติ |
| ใส่รหัสผ่าน | `protect.js` | เข้ารหัสด้วย @cantoo/pdf-lib + ตั้งสิทธิ์ พิมพ์/คัดลอก/แก้ไข |
| เซ็นเอกสาร | `sign.js`, `js/editor.js` | วาด / อัปโหลด (ลบพื้นขาว) / พิมพ์, จำลายเซ็นไว้ในเครื่อง |
| เพิ่มข้อมูลใน PDF | `form.js`, `js/editor.js` | ข้อความ (ภาษาไทย), สัญลักษณ์ ✓ ✗, วันที่, รูปภาพ |

## รัน

ต้องเปิดผ่าน web server (เปิดไฟล์ตรงแบบ `file://` ไม่ได้ เพราะใช้ ES modules)

```bash
python -m http.server 8765
```

แล้วเปิด http://localhost:8765

## Deploy

เป็น static site ล้วน — ลากทั้งโฟลเดอร์ไปวางใน Netlify / GitHub Pages / Cloudflare Pages ได้เลย

## ไลบรารี (อยู่ใน `vendor/`, ใช้แบบ offline ได้)

pdf-lib (@cantoo fork, รองรับเข้ารหัส) · pdf.js 3.11 · JSZip · SortableJS · pako
ฟอนต์ไทยโหลดจาก Google Fonts (Sarabun, Charm, Mali, Itim, Srisakdi) — ถ้าออฟไลน์จะใช้ฟอนต์ของระบบแทน

ข้อความภาษาไทยทุกจุด (เลขหน้า ลายน้ำ ข้อความในฟอร์ม) วาดผ่าน canvas แล้วฝังเป็นภาพ PNG ความละเอียด 4 เท่า เพื่อให้สระ/วรรณยุกต์ถูกต้องเสมอ
